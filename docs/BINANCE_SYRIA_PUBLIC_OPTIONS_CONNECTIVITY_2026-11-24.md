# اختبار اتصال خيارات Binance من شبكة Syriatel السورية

**التاريخ:** 24 نوفمبر 2026  
**مصدر القياس:** سجلات Supabase Edge Function v10، مع بيانات Cloudflare للطلب  
**النطاق:** بيانات السوق العامة فقط؛ لا مفاتيح API خاصة ولا أوامر تداول.

## النتيجة

تم تسجيل **50 استجابة HTTP 200** لطلبات واجهة خيارات Binance العامة خلال الفترة **07:00:20.433–07:00:27.573 UTC**. صنّف Cloudflare مصدرها كالتالي:

- البلد/المدينة: SY / Damascus
- الشبكة: 3G Syriatel Mobile Telecom
- Cloudflare colo: LHR
- User-Agent: Chrome 158 على iPhone / iOS 27.0.1
- عنوان العميل: عنوان واحد مميز ضمن هذه الدفعة (لا يُحفظ أو يُنشر هنا)
- Origin وReferer: غير موجودين في السجلات؛ لذلك لا نثبت أن الطلبات انطلقت من صفحة GitHub Pages تحديداً.

## توزيع الطلبات الناجحة

| Endpoint | الطلبات | HTTP |
|---|---:|---:|
| exchangeInfo | 1 | 200 |
| mark | 1 | 200 |
| ticker | 1 | 200 |
| index | 10 | 200 |
| openInterest | 36 | 200 |
| depth | 1 | 200 |
| **الإجمالي** | **50** | **200** |

الموصل يستخدم المضيف الرسمي `https://eapi.binance.com`، وليس Binance.US. في Edge Function v10 يُعاد رمز حالة Binance upstream كما هو؛ لا يُحوَّل خطأ upstream إلى 200، كما لا تُخزَّن في الذاكرة المؤقتة إلا الاستجابات التي يكون فيها `upstream.ok` صحيحاً. لذلك تعني هذه السجلات أن طلبات هذه الدفعة وصلت إلى واجهات Binance العامة وأعادت JSON مع HTTP 200، لا مجرد أن Supabase أجاب بنجاح.

## ما الذي تثبته النتيجة؟

1. مسار شبكة Syriatel المصنّف في دمشق استطاع الوصول عبر موصل Volterra إلى ستة endpoints عامة لخيارات Binance.
2. نجح جلب كتالوج العقود، Mark، Ticker، Index، Open Interest ولقطة Depth من ذلك المسار.
3. هذه نتيجة اتصال عامة من شبكة سورية، وليست نتيجة من Binance.US أو من عنوان VPN أجنبي.

## ما الذي لا تثبته؟

- لا تثبت أن الطلبات جاءت حتماً من صفحة GitHub Pages؛ لم يُرسل Origin أو Referer.
- لا تثبت ملكية الجهاز أو هوية مستخدمه؛ سجلات الشبكة وUser-Agent قرائن تقنية وليست إثبات هوية.
- لا تثبت KYC أو تفعيل Options داخل حساب Binance أو أهلية منتج فرعي أو صلاحية البيع/الكتابة.
- لا تثبت قانونية التداول أو تسمح بتفعيل التنفيذ الحي.
- هذه ليست بيانات مصادقة؛ endpoints المختبرة عامة ولا تتطلب مفاتيح تداول موقعة.

## المقارنة مع بقية السجلات

في نافذة السجلات نفسها ظهرت أيضاً طلبات من الولايات المتحدة أعادت 451، وطلبات ناجحة من المملكة المتحدة. لا يجوز استخدام نتائج تلك الشبكات لنفي أو إثبات نتيجة Syriatel؛ لكل مسار شبكته ونتيجته. الاختبار السوري مستقل في هذه الدفعة: 50 طلباً، عنوان عميل واحد، وشبكة مصنفة Syriatel في دمشق.

## القرار التشغيلي
