# تقييم مزودي بيانات الخيارات — 24 نوفمبر 2026

## القرار التنفيذي

لا يوجد ضمن سقف 15 دولاراً شهرياً مصدر واحد موثق يغطي جميع الخيارات المدرجة عالمياً عبر الأسهم والمؤشرات والعقود الآجلة (الفائدة والعملات والطاقة والمعادن والزراعة) والكريبتو، مع بيانات قابلة لإعادة العرض داخل موقع عام وترخيص واضح.

لذلك لا نشتري اشتراكاً ولا نضيف موصلاً حياً إلى الإنتاج الآن. نعتمد طبقات بيانات مستقلة:
1. Binance Crypto Options كموصل تقني قائم فقط للمنتجات التي يعيدها فعلياً، مع اعتبار HTTP 451 رفضاً من upstream يجب تشخيص نطاقه دون محاولة الالتفاف عليه.
2. Massive Options Basic كمصدر مرشح مجاني لبيانات نهاية اليوم والمرجع التاريخي لخيارات الولايات المتحدة، للاستخدام الشخصي/الداخلي فقط وبعد التحقق من شروط الحساب.
3. Alpaca Indicative كمرشح مجاني ثانٍ لبيانات خيارات الولايات المتحدة المؤشرة/المعدّلة والمتأخرة، بشرط تأكيد قبول الحساب من سوريا وشروط الاستخدام؛ لا نعتبرها OPRA NBBO ولا أسعار تنفيذ.
4. MarketData.app Free كمصدر اختياري لبيانات خيارات أمريكية تاريخية متأخرة 24 ساعة بحد 100 رصيد API يومياً وسنة واحدة، للاستخدام الداخلي فقط.
5. CME Group وCboe وXignite كمصادر مؤسسية/مرخصة للمراحل اللاحقة، وليست حلولاً مجانية شاملة ضمن الميزانية الحالية.

## نتائج التحقق التفصيلية

### 1. Massive

- خطة Options Basic معلنة مجاناً.
- تغطي جميع رموز الخيارات الأمريكية المتاحة لديها، مع 5 طلبات API في الدقيقة وبيانات نهاية اليوم وسنتين تاريخيتين.
- مرجع العقود متاح، بينما الـsnapshots والـquotes اللحظية/المتأخرة لا ينبغي افتراض أنها ضمن الخطة المجانية.
- مناسبة لتكوين أرشيف يومي بعد إغلاق الجلسة والتحليل التاريخي الأولي، وليست مصدراً لأسعار قابلة للتنفيذ.
- صفحة الأسعار تصنفها للاستخدام الفردي؛ لا نعيد نشر البيانات داخل الموقع العام دون إذن صريح.

المصادر:
- https://massive.com/options
- https://massive.com/pricing?product=options
- https://massive.com/docs/rest/options

### 2. Alpaca

- خطة Basic مجانية وتشمل بيانات خيارات أمريكية عبر Indicative Pricing Feed.
- وثائق Alpaca تصف indicative بأنه مشتق من OPRA؛ الأسعار ليست أسعار OPRA الأصلية، والصفقات متأخرة 15 دقيقة، كما أن بيانات التاريخ المتاحة منذ فبراير 2024.
- endpoint سلسلة الخيارات والـsnapshots يعرض آخر صفقة وآخر quote وGreeks، لكن يجب وسم كل حقل بمصدره ودرجة تأخيره.
- الوصول يتطلب API credentials. لا نطلب مفاتيح ولا نضيفها إلى GitHub أو المتصفح.
- صفحات توفر الدول تطلب التواصل لمعرفة قبول الدولة؛ لم نعثر على تأكيد رسمي لقبول مقيم سوريا. لا يُنشأ حساب أو يُعتمد كمصدر قبل تأكيد مكتوب.
- لا يوجد في الأدلة التي راجعناها تصريح واضح بإعادة توزيع feed داخل منتج عام.

المصادر:
- https://docs.alpaca.markets/us/docs/about-market-data-api
- https://docs.alpaca.markets/us/docs/historical-option-data
- https://docs.alpaca.markets/us/reference/optionchain
- https://alpaca.markets/support/countries-alpaca-is-available

### 3. MarketData.app

- Free Forever: 100 API credits يومياً، 24 ساعة تأخير على الخيارات، وسنة واحدة من البيانات التاريخية.
- الحساب المجاني لا يحصل على بيانات اليوم الحالي؛ البيانات التاريخية تصبح متاحة بعد افتتاح جلسة اليوم التالي.
- Starter يعرض 15 دقيقة تأخير بسعر 12 دولاراً شهرياً عند الالتزام السنوي، أو 30 دولاراً شهرياً عند الدفع الشهري؛ لكنه لا يحقق شرط عدم الالتزام السنوي.
- شروط الخطط الذاتية تصف الاستخدام بأنه داخلي؛ عرض البيانات للمستخدمين أو إعادة توزيعها يتطلب الخطة التجارية التي تبدأ من 333 دولاراً شهرياً.
- لا تستخدم هذه البيانات كعرض عام في Volterra.

المصادر:
- https://www.marketdata.app/pricing/
- https://www.marketdata.app/docs/account/free-accounts/
- https://www.marketdata.app/docs/account/plan-limits/
- https://www.marketdata.app/data/

### 4. Cboe

- تجربة All Access تعرض 500 نقطة يومياً لمدة 14 يوماً مع تفويض بطاقة.
- السعر الأساسي لا يشمل تراخيص SIP؛ أسعار الخيارات الحية أو المتأخرة تتطلب اشتراك OPRA.
- لذلك لا يجوز وصف تجربة Cboe بأنها feed خيارات مجاني. البيانات التاريخية/غير SIP قد تكون متاحة ضمن نطاق الخطة، لكن ذلك لا يحل احتياجنا إلى NBBO مرخص.
- لا نبدأ التجربة لأن وجود بطاقة/تجربة ليس تفويضاً بإنفاق لاحق، ولأن OPRA قد يرفع التكلفة فوق السقف.

المصادر:
- https://datashop.cboe.com/cboe-all-access-api
- https://datashop.cboe.com/option-quote-intervals
- https://www.cboe.com/solutions/options-analytics/historical-data/

### 5. CME Group

- واجهة WebSocket سحابية لبيانات futures/options، مع top-of-book والصفقات والإحصاءات اليومية.
- التسعير المنشور يبدأ من 0.50 دولار/GB، لكن رسوم ILA/الترخيص تنطبق أيضاً.
- يغطي مجموعة من قطاعات الفيوتشرز، وليس كل الأسواق العالمية أو كل الخيارات على الأسهم.
- نحتاج عرضاً مكتوباً يوضح رسوم الوصول والبيانات الشخصية وحقوق التخزين/العرض قبل أي تفعيل.

المصدر:
- https://www.cmegroup.com/market-data/real-time-futures-and-options-data-api.html

### 6. Xignite وORATS

- Xignite Global Options يعلن عن خيارات أمريكية ودولية مؤجلة مع chain/OI/volume وبيانات العقد، لكن لا ينشر سعراً عاماً؛ لا يمكن اعتباره ضمن الميزانية قبل عرض سعر.
- ORATS ينشر API مؤجلاً يبدأ من 199 دولاراً شهرياً؛ يتجاوز الحد الحالي، لذا لا يُعتمد.

المصادر:
- https://www.xignite.com/product/global-option-price-data/
- https://orats.com/data-api

## قواعد الدمج المعتمدة

لا يظهر أي مزود جديد في واجهة Volterra كـLIVE قبل اكتمال كل البنود:
- تحقق شروط الحساب وبلد الإقامة والكيان المتعاقد.
- تأكيد حقوق الاستخدام الشخصي/الداخلي أو العرض العام بحسب وجهة البيانات.
- اختبار endpoint فعلي من بيئة النشر المسموح بها.
- توثيق asset class وvenue وinstrument identifier وcontract multiplier وexercise/settlement وquote currency.
- توثيق source timestamp وreceived timestamp وdelay class لكل حقل.
- التمييز بين OPRA/NBBO وindicative وEOD وdelayed وsynthetic/model-derived.
- اختبارات adapter conformance واختبارات schema drift وrate limits وstale data.
- عدم استخدام مزود بديل تلقائياً عند الرفض الجغرافي أو فشل الأهلية.
- عدم إدخال أسرار API في browser bundle أو Git history أو سجلات CI.
- لا اشتراك مدفوع أو بطاقة/تجربة قابلة للتحول إلى اشتراك دون موافقة إنفاق منفصلة.

## ترتيب التنفيذ

1. الحفاظ على Binance كموصل قائم مع إظهار upstream status بدقة.
2. إعداد adapter اختباري محلي لـMassive EOD دون تفعيل حساب أو تخزين مفتاح.
3. إعداد adapter اختباري لـAlpaca Indicative فقط بعد تأكيد رسمي لقبول الدولة وحقوق الاستخدام.
4. تقييم CME لقطاع futures options بعرض سعر مفصل؛ لا نفترض أن رسوم 0.50/GB هي التكلفة الكاملة.
5. إنشاء واجهة مصدر بيانات موحدة تمنع الخلط بين مزودين أو درجات تأخير مختلفة.
6. بناء أرشيف تاريخي من مصادر تسمح بالتخزين وإعادة التشغيل؛ لا نستخدم بيانات مجانية لا تسمح شروطها بذلك.

## الخلاصة

المسار الواقعي ضمن الميزانية هو مزيج من مصادر منفصلة: Binance حيث يسمح المصدر، ومصدر أمريكي EOD/indicative للبحث الشخصي بعد التحقق من الأهلية والحقوق، وCSV لمصادر مرخصة أخرى. لا يوجد حل واحد مجاني أو أقل من 15 دولاراً يحقق تغطية عالمية وخيارات حية وترخيص عرض عام. يجب إبقاء التغطية الحية الفعلية ضيقة وصريحة بدلاً من ادعاء شمول غير موجود.
